# Shibam Mishra — Personal Developer Portfolio 🚀

A high-performance, modern, brutalist-inspired interactive personal developer portfolio built with **React 18**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

Designed and crafted for **Shibam Mishra** (BCA 2023–2026, SAM College of Engineering & Technology, Barkatullah University, Bhopal).

---

## ⚡ Key Highlights & Features

- **🎯 Web & Software Focus**: Highlights full-stack web engineering, Core Java (OOP, Collections), and MySQL database architecture.
- **🧭 Interactive Career Journey (01 ➔ 05)**: Pinned kinetic subway scrubber moving seamlessly from Station 01 Jamshedpur to Station 05 IT Destination.
- **⚡ Hardware-Accelerated Infinite Marquee**: 60fps technical arsenal ticker featuring React, TypeScript, Java, SQL, Git, and academic credentials.
- **🎯 10-Ball Spring Physics Trailing Cursor**: Native Canvas / Framer Motion spring trailing cursor with interactive hover morphing (touch-safe on mobile).
- **📱 100% Mobile & Aspect Ratio Responsive**: Zero horizontal overflow, compact bottom dock, responsive ID cards, and fluid layouts for all phones, tablets, and laptops.
- **🔊 Tactile Audio Feedback**: Native Web Audio API sound synthesis without external mp3 asset dependencies.
- **📄 Interactive Resume & Project Modals**: Complete modal viewers for production projects (Student Result System, Dance Platform, Portfolio) and one-click printable resume.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone git@github.com:ishibammishra/Portfolio.git

# Navigate into the project directory
cd Portfolio

# Install dependencies
npm install

# Start the local development server
npm run dev
```

Visit `http://localhost:3000` in your browser.

### Building for Production

```bash
npm run build
```

The output will be placed in the `dist/` directory, ready for deployment on Vercel, Netlify, or GitHub Pages.
